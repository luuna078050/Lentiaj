# Установка тестовой версии

1. Откройте приложение по HTTPS-адресу (например, через GitHub Pages после публикации репозитория).
2. В Chrome выберите «Добавить на главный экран» / «Установить приложение».
3. После установки Lenchay открывается как отдельное приложение.
4. Другому человеку можно отправить тот же HTTPS-адрес.

Важно: ZIP/HTML-файл сам по себе не устанавливает APK. Для настоящего APK нужен отдельный Android build. Эта версия подготовлена как устанавливаемый PWA и не требует магазина приложений.
