# Сетевой контур Lenchay

Текущий прототип использует `library.json` как общую опубликованную библиотеку рецептов.

Клиент может читать общую библиотеку без авторизации. Запись новых данных в общую библиотеку намеренно не выполняется из браузера: публичный токен GitHub в клиент встраивать нельзя.

Следующий этап: отдельный backend API с авторизацией, например:
- GET /library
- POST /library/recipes
- POST /library/sync
- GET /health

Это позволит нескольким пользователям отправлять рецепты/данные в общую библиотеку безопасно.
