# QA checklist — Lenchay test

Проверить на Android Chrome:

- [ ] Открытие Главной
- [ ] «Начать ленивиться» запускает голосовой режим при поддержке браузера и показывает fallback
- [ ] «Сканировать» открывает тестовый сценарий и добавляет продукт
- [ ] Продукты: добавление и удаление
- [ ] Покупки: чекбоксы и «Магазины рядом»
- [ ] Геолокация: разрешение / отказ / ошибка сети
- [ ] Рецепты: библиотека и классические рецепты
- [ ] «У меня есть аперитивчик»: выбор напитка и варианты
- [ ] Все вкладки возвращаются без перезагрузки
- [ ] После установки PWA повторное открытие работает без сети для закешированных ресурсов
- [ ] Общая библиотека читается из `library.json`

Ограничение: настоящая запись в общую библиотеку и авторизация пока не включены.
