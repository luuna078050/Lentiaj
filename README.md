# Ленивец — MVP

Минимальная рабочая версия приложения «Ленивец».

## Продуктовая модель
- **FREE — $0:** базовые рецепты и рекомендации + реклама.
- **BASIC — $5/месяц:** без рекламы + вариации блюд, работа с остатками и первая половина расширенных функций.
- **PREMIUM — $10/месяц:** всё BASIC + мировая кухня, глубокая память, глобальная база, пользовательские рецепты, региональные рейтинги и вторая половина расширенных функций.
- **PRO:** позже, после накопления достаточного объёма функций и данных.

## Новый модуль: «Комплимент от шеф-повара»
Персональная ежедневная подборка пользовательских/авторских рецептов, отобранных по текущему набору продуктов пользователя и региональным рейтингам.

- показывается и в FREE, и в BASIC как ограниченная витрина Premium-контента;
- привязывается к тому, что уже есть у пользователя в холодильнике/кладовой;
- во FREE — мягкий рекламно-промоционный формат без превращения в навязчивую рекламу;
- в BASIC — до **5 комплиментов в день**, без рекламы;
- подборка обновляется ежедневно и не должна зависать на одном рецепте несколько дней;
- Premium получает расширенный доступ к глобальной базе, региональным рейтингам и пользовательским рецептам.
