# Лентяй / Lenchay

Тестовая версия кухонного помощника для Android/iOS.

## Версия 0.2

- утверждённый интерфейс без мультипликации;
- стартовый режим **«Начать ленивиться»**;
- голосовой сценарий: «Привет. А ну-ка, покажи закрома»;
- тестовое распознавание продуктов;
- добавление и удаление продуктов;
- библиотека классических/«бессмертных» рецептов, включая домашний майонез;
- блок «Можно приготовить сейчас» и «Требуется докупить»;
- список покупок;
- поиск магазинов рядом через геолокацию и открытую карту;
- «У меня есть аперитивчик»;
- PWA/offline cache;
- общая библиотека рецептов: чтение из `library.json` и подготовленный API для публикации.

## Сетевой контур

`server.js` — тестовый backend с:

- `GET /health`
- `GET /api/library`
- `POST /api/library/recipes`

`render.yaml` подготовлен для размещения сервера. Клиент сначала пытается читать общую библиотеку через API, затем использует `library.json` как fallback.

Публикация рецепта в общий контур выполняется через форму «Добавить рецепт в общую библиотеку».

**Важно:** это тестовый сетевой контур без авторизации. Перед публичным production-запуском нужны авторизация, защита API, rate limiting и постоянное хранилище.

## Установка

При размещении по HTTPS приложение можно установить как PWA через Chrome → «Установить приложение» / «Добавить на главный экран». Настоящий APK пока не собирается; это сделано намеренно на этапе тестирования интерфейса и сетевого контура.
