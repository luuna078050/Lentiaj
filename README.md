# Лентяй / Lenchay

Тестовая версия кухонного помощника для Android/iOS.

## Что уже работает в тестовой версии

- основной интерфейс без мультипликации;
- утверждённые смысловые слоганы в интерфейсе;
- вкладки «Главная», «Продукты», «Покупки»;
- тестовое сканирование продуктов (имитация распознавания);
- добавление и удаление продуктов;
- подбор блюд: «Можно приготовить сейчас» и «Требуется докупить»;
- список покупок;
- режим «У меня есть аперитивчик»;
- заготовка голосового ввода;
- заготовка «Где купить».

## Концепция

«Лентяй» понимает, какие продукты есть у пользователя, предлагает блюда из имеющихся продуктов и помогает докупить недостающие ингредиенты.

Главный принцип:

> Увидел продукты → понял, что есть → предложил, что приготовить → помог докупить недостающее.

Главный экран использует слоганы:

> «Не хочешь думать — не думай.»
>
> «Не хочешь выбирать — не выбирай.»
>
> «Открой холодильник — Лентяй решит.»

## Важно

Это именно тестовая UI/логическая версия. Мультипликация, настоящее компьютерное зрение, полноценное распознавание речи, база рецептов, реальные магазины/доставка и production backend пока не подключены.

## Запуск

Открой `index.html` в браузере или размести содержимое репозитория на любом статическом хостинге. Версия сделана как лёгкий PWA-прототип без внешних зависимостей.
