# Ленивец — MVP

Минимальная рабочая версия приложения «Ленивец».

## Что уже есть
- главный экран;
- продукты;
- рекомендации с логикой 100% / ≈85% / купить / заменить;
- «Наши лучшие рецепты» с Top-20 и статусом константы;
- история и опыт;
- чат;
- настройки диетических режимов, аллергий/непереносимостей и языка;
- сканер и результаты сканирования;
- базовый safety-first UX.

## Сборка
GitHub Actions автоматически собирает debug APK при push в `main` или `mvp/**`.
