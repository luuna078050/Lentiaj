# Лентяй

Инициативный кухонный помощник для Android и iOS.

## Концепция

«Лентяй» — приложение, которое понимает, какие продукты есть у пользователя, предлагает блюда из имеющихся продуктов и помогает докупить недостающие ингредиенты.

Главный принцип:

> Увидел продукты → понял, что есть → предложил, что приготовить → помог докупить недостающее.

---

## 1. Видеораспознавание продуктов

Пользователь включает режим видеосканирования и водит камерой по:

- холодильнику;
- кухонным полкам;
- столу;
- отдельным продуктам.

Приложение распознаёт продукты и формирует текущий инвентарь.

Распознавание должно учитывать:

- плохое освещение;
- блики;
- частично закрытые продукты;
- упаковку;
- похожие объекты;
- разные ракурсы;
- продукты, которые невозможно уверенно определить.

Если система не уверена в результате, она не должна молча добавлять сомнительный продукт.

Она должна мягко попросить уточнение:

> «Кажется, я не совсем уверена, что это. Подскажешь, пожалуйста, что здесь?»

Пользователь может ответить голосом.

---

## 2. Голос

Голос является полноценной частью интерфейса.

С помощью голоса пользователь может:

- добавить продукт;
- исправить распознавание;
- уточнить количество;
- удалить продукт;
- выбрать блюдо;
- спросить, что можно приготовить;
- включить режим аперитива;
- ответить на инициативное предложение.

Обращение и голос могут быть персонализированы под пользователя.

---

## 3. Инвентарь

После распознавания формируется текущий набор продуктов.

Для продукта желательно хранить:

- название;
- категорию;
- количество;
- единицу измерения;
- уверенность распознавания;
- при необходимости срок годности;
- способ добавления: камера / голос / вручную.

Названия продуктов необходимо нормализовать.

Например:

`яйцо`, `куриное яйцо`, `яйца куриные`

должны рассматриваться как один тип продукта, а не как три разных продукта.

---

# 4. Подбор блюд

После формирования инвентаря приложение анализирует библиотеку рецептов.

Результаты делятся на два основных блока.

## Можно приготовить сейчас

Первым выводится список блюд, для которых всё необходимое уже есть.

Например:

**Можно приготовить сейчас — 3 блюда**

1. Омлет с овощами
2. Курица с сыром
3. Запеканка

Эти блюда должны находиться выше вариантов, требующих покупки.

---

## Требуется докупить

Ниже выводятся блюда, для которых не хватает ингредиентов.

Например:

**Паста с курицей и грибами**

Требуется докупить:

- шампиньоны;
- сливки.

Следующее блюдо может требовать:

- картофель;
- лук.

Для каждого блюда должна отображаться отдельная графа:

**Требуется докупить**

с конкретным перечнем продуктов.

---

# 5. Единый список покупок

Если пользователь выбрал несколько блюд, приложение объединяет недостающие продукты.

Например:

**Нужно купить:**

- картофель — 1 кг;
- лук — 2 шт.;
- шампиньоны — 300 г;
- сливки — 200 мл.

Дубликаты должны объединяться.

Пользователь не должен вручную собирать список из каждого рецепта.

---

# 6. Покупка и доставка

После формирования списка покупок появляется возможность:

**«Где купить»**

Приложение может искать:

- ближайшие магазины;
- магазины с онлайн-заказом;
- сервисы доставки;
- варианты самовывоза.

В дальнейшем возможно:

**«Заказать продукты»**

с передачей сформированного списка в подходящий магазин или сервис.

Логика должна учитывать:

- расстояние;
- наличие товара;
- цену;
- стоимость доставки;
- время доставки;
- возможность самовывоза.

---

# 7. «У меня есть аперитивчик»

Отдельная функция интерфейса:

## «У меня есть аперитивчик» 🍾

Пользователь нажимает её и указывает, что у него есть, например:

- шампанское;
- вино;
- другой напиток.

После этого «Лентяй» анализирует:

1. какой напиток имеется;
2. какие продукты уже есть;
3. какие блюда и закуски подходят к напитку;
4. чего не хватает.

И показывает варианты именно под этот аперитив.

Например:

**🥂 У меня есть шампанское**

> «Вот что можно подобрать к нему из того, что уже есть дома.»

Если чего-то не хватает, используется обычная логика:

**Требуется докупить**

---
