# Тестовая версия Lenchay — контроль связности

## Основные переходы
1. Главная → Начать ленивиться → голосовой режим / камера.
2. Главная → Сканировать → тестовое распознавание → Продукты.
3. Главная → У меня есть аперитивчик → выбор напитка → варианты закусок.
4. Главная → блюдо → приготовление.
5. Продукты → Добавить/Удалить → обновление инвентаря.
6. Покупки → Магазины рядом → геолокация → ближайшие магазины.
7. Рецепты → общая библиотека → выбор рецепта.

## Проверки
- Нет битых кнопок.
- Каждая вкладка открывает свой экран.
- Добавление/удаление меняет инвентарь.
- Покупки отображаются независимо от рецептов.
- Геолокация имеет понятный отказоустойчивый сценарий.
- Голос имеет fallback на текст/камеру.
- Мультипликация намеренно отсутствует.
- Сетевой контур библиотеки пока read-only/заготовка; запись общего контента не выполняется из клиента без авторизации.
