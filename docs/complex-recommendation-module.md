# Модуль «Можно чуть-чуть заморочиться»

## Назначение

Ленивец не ограничивается быстрыми и ленивыми решениями. Если при анализе холодильника обнаружены продукты, из которых можно сделать более сложное блюдо, система должна **учесть это и предложить пользователю второй уровень выбора** — без навязывания.

Пример:

> «Вижу размороженное мясо. Если хочешь просто поесть — вот быстрый вариант. А если сегодня можно чуть-чуть заморочиться, из этой лопатки можно сделать более сложное блюдо.»

## Приоритет выдачи

1. **Можно прямо сейчас** — максимальное совпадение и минимум действий.
2. **Можно с заменой** — не хватает одного/нескольких ингредиентов, но есть разумная замена.
3. **Можно докупить** — недостающий ингредиент доступен для покупки; при разрешённой геолокации показать варианты рядом.
4. **Можно чуть-чуть заморочиться** — более сложный рецепт, если сырьё и оборудование позволяют.
5. **Более сложный вариант** — для пользователя, который явно хочет готовить.

## Контекст сырья

Модуль учитывает:

- тип продукта и часть туши/вид сырья, если распознано;
- степень свежести и историю хранения;
- размороженный/свежий продукт;
- доступное оборудование пользователя;
- уже известные диетические ограничения и аллергии;
- индивидуальные предпочтения;
- время и усилия.

## Оборудование

Если пользователь указал или система знает, что есть мультиварка, аэрогриль, духовка, кухонный комбайн или другой автоматизированный прибор, Ленивец может предложить рецепт, который требует больше подготовки, но мало ручного контроля.

Пример формулировки:

> «Если у тебя есть мультиварка, можно закинуть всё туда и оставить готовиться. Самому возиться почти не придётся.»

## Правило UX

Более сложные рецепты **не должны вытеснять простой ответ**. Сначала пользователь получает решение «что можно сделать сейчас», а затем ненавязчиво видит блок:

### «Если хочешь заморочиться»

Внутри — 1–3 подходящих варианта с оценкой сложности, временем активной работы, общим временем и необходимым оборудованием.

## Безопасность

Для скоропортящегося/размороженного сырья safety-check выполняется **до** предложения рецепта. Сомнительное сырьё не должно становиться ингредиентом только потому, что рецепт хорошо совпал.
