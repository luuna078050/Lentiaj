# Ленивец — локализация и запуск 2026

## Языковая архитектура

Язык интерфейса, регион и кулинарная культура пользователя — отдельные настройки.

### Китайские разновидности
Не смешивать «китайский» и один универсальный голосовой профиль. Базовый слой — Mandarin/Putonghua. Архитектура должна позволять добавлять отдельные речевые/лексические профили для Yue/Cantonese, Wu (Shanghai), Min (включая Hokkien/Taiwanese), Hakka, Xiang, Gan и Jin/Huizhou/Pinghua там, где есть подтверждённые данные и пользовательский спрос.

Голосовой ввод должен сначала определять язык/разновидность, затем нормализовать смысл в общий food-intent слой. Ответ пользователю возвращается в выбранном им языке/варианте.

## Маркетинговая идея

Позиционирование: «Открой холодильник. Ленивец разберётся, что приготовить.»

Дополнительный эмоциональный слой: помощь человеку, который устал, живёт один или не хочет принимать ещё одно бытовое решение. Не обещать лечение одиночества и не использовать уязвимость как манипуляцию; коммуникация — про уют, поддержку и простое действие.

## Контентный дистрибьютор

Создать не спам-бота, а Content Distribution Assistant:
- хранит локализованные варианты роликов/постов;
- выбирает регион и язык;
- адаптирует текст и CTA;
- ведёт календарь публикаций;
- публикует только через официальные API/разрешённые инструменты;
- собирает CTR, installs, trial starts, Basic/Premium conversions;
- отключает слабые креативы и предлагает новые варианты.

## $100 тестового бюджета

Не распределять равномерно. Первые $100 — это эксперимент, а не попытка купить тысячи установок.

- $25 — Japan
- $25 — South Korea
- $25 — Europe/English
- $25 — creative retest / победивший рынок

Китай на первой неделе — органический/партнёрский тест и подготовка локальной дистрибуции; платный бюджет не расходовать до проверки платформы, compliance и трекинга.

## KPI

Главные метрики:
- CPI/CPA install
- D1/D7 retention
- first scan rate
- recipes viewed per active user
- 3-day trial start rate
- Basic conversion
- Premium conversion
- AD-Free conversion
- ARPU
- revenue per active user

Цель $5,000 в первый месяц — stretch goal, а не базовый прогноз. При бюджете $100 она не достигается покупкой трафика сама по себе; нужен органический охват/UGC/виральность или партнёрский трафик. Главный эксперимент первого месяца — найти 1–2 локальных креатива, которые дают дешёвый органический/платный install и последующую оплату.
